# Pour Codex

1. Lis `PROJET.md` en entier : ce sont tes consignes (les mêmes que Claude Code).
2. Lis `TABLEAU.md` : tes tâches sont les lignes « X ». Mets ta ligne à jour quand tu commences et quand tu finis.
3. Tu ne modifies QUE : `js/textes/`, `js/exercices/`, `js/enregistrement/`, `js/progression/`, `js/affichage/`, `js/memorisation/`, `css/affichage.css`, `tests/codex/`, et tes lignes de `TABLEAU.md`.
4. Une branche par tâche : `codex/<tache>`. Tu ne fusionnes jamais dans `main` (c'est Claude Code).
5. Tests : `npm test` (sans Internet) et `npm run test:en-ligne` (vérifie les vrais sons). Ajoute des tests pour chaque partie que tu fais, dans `tests/codex/`.
6. Tu n'écris JAMAIS de texte arabe toi-même. Un doute → tu l'écris dans « Questions pour Zakou » de `TABLEAU.md` et tu attends.
